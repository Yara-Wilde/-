# 图书管理系统
本项目为C++课程设计，包含两个版本：C++控制台版本、Qt图形窗口版本（Qt4.2.1）。

## 功能介绍
1. 添加图书
2. 展示全部图书
3. 根据书名查询图书
4. 图书借阅（库存自动减1）
5. 图书归还（库存自动加1）

## 开发环境
- 控制台版本：C++，小熊猫C++
- Qt图形版本：Qt 4.2.1，Qt Widgets
> 数据存储在内存，程序关闭之后数据清空。

## 文件说明
- main.cpp：程序入口
- mainwindow.h：头文件，类声明
- mainwindow.cpp：界面与业务逻辑实现

## 运行方式
Qt版本：新建QMainWindow项目，替换对应h、cpp代码，qmake后构建并运行。
控制台版本：直接复制代码，在小熊猫C++编译运行。
